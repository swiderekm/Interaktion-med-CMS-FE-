Interaktion med CMS – Frontend

Frontend project created as part of the Interaction with CMS course.

The project demonstrates how a frontend application can interact with a Strapi CMS through an API and display content managed through the CMS.

The project was developed by myself as a form of examination.

Technologies
Frontend: HTML, CSS, JavaScript
CMS: Strapi
API
⚠️ Backend unavailable

The original Strapi backend is no longer available. It was hosted using Strapi's "Free forever" plan, which was later discontinued.

The project must be hosted locally in order for all the data to be loaded, using this repository and the backend part which is avalibe on my profile

Because the frontend relies on the Strapi API, some functionality may no longer work.
